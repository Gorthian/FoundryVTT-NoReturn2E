# Kompendien

Das System bringt **16 Compendien** mit (751 Einträge). Sie enthalten Spielwerte und **eigene Kurzfassungen mit Seitenverweisen** auf das Corebook 2E, aber keine vollständigen Regeltexte. Für die Regeln wird das Buch benötigt.

| Compendium | Inhalt |
|---|---|
| Spezies | Spielbare Spezies |
| Waffen | 87 Waffen |
| Munition | Munition und Sprengstoffe |
| Rüstungen | Schutzkleidung |
| Ausrüstung | Ausrüstungsgegenstände |
| Augmentierung | Robotik, Implantate, Ganzkörper-Pakete, Designoptionen |
| PSI-Kräfte | 12 Kräfte |
| PSI-Apps | 180 Apps |
| Style-Skills | Style-Skills und 16 Kampfkünste |
| Abnormitäten | Abnormitäten |
| Bio-Eigenschaften | Biologische Eigenschaften |
| Vor-/Nachteile | Vorteile und Nachteile |
| Merkmale | 128 Charaktermerkmale |
| Fertigkeiten | Besondere Fertigkeiten |
| Tabellen | Rolltables: Trefferzonen, PSI-Fehlschlag, Degeneration, Butterfly Effect |
| Regeln | Regel-Journal (Kurzfassungen mit Seitenverweisen) |

Items lassen sich per Drag & Drop auf Charakterbögen ziehen. Der [Charaktergenerator](Charaktergenerator) nutzt die Compendien direkt.

Was in den Compendien noch fehlt (Fahrzeuge, Kreaturen, Drogen, Getränke u. a.), steht unter [Bekannte Lücken](Bekannte-Luecken). Wie die Compendien erzeugt werden, beschreibt [Mitwirken und Releases](Mitwirken-und-Releases).
